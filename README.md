# Canteen Rush

A VR food-service game built in Unity 6 (URP, XR Interaction Toolkit) from the PES University "Outdoor" floor assets: grab donuts, colas, shakes and cakes in the canteen, fill cups at the water cooler, load a tray and carry it out to customers on the patio. Mini-project for the AR/VR course: interaction, spatial audio, haptics, UI and lighting, optimised for Quest-class hardware and demonstrated through the XR Device Simulator.

Status: planning complete, implementation not started. Start with `docs/00_MASTER_SPEC.md`.
